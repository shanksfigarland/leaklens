# LeakLens Roadmap

## Near Term

1. Add provider-specific validators behind explicit opt-in
2. Add diff / PR-focused scan mode
3. Add better grouping and suppression policy files
4. Add richer HTML filtering and incident pivoting
5. Add automatic report opening and operator UX polish

## Medium Term

1. Parallelize more of the git-history scan path
2. Add first-seen / last-seen branch attribution
3. Add more provider detectors and confidence refinements
4. Add stronger baseline management and false-positive workflows
5. Add a local web dashboard for browsing findings

## Longer Term

1. Optional remote or local LLM triage providers
2. Validator plugins for selected providers
3. CI / GitHub Action packaging
4. Structured policy packs for org-specific rules
5. Secret lineage views across multiple repositories
